# Architect Common Spec

## Goal

挙動を変えずに、責務境界と構造を改善する。

## Use This Skill To

- 長いファイルや長い関数を分割する
- 重複ロジックを整理する
- 責務の混在を解く
- ディレクトリやモジュールの配置を整える

## Shared Checks

- 各ファイルを1文で説明できるか
- 同じパターンが重複していないか
- 無関係な責務が混ざっていないか
- 1つの関数が仕事を持ちすぎていないか

## Shared Workflow

1. 最小の構造問題を見つける
2. 必要な境界だけを動かす
3. 挙動を保ったまま形を直す
4. 関連テストや検証を再実行する

## Guardrails

- 全部を一度に直さない
- 見た目だけのために挙動変更しない
- 構造問題以上にスコープを広げない
