# vibe-diff

## 発火条件

`hook_pre_commands.sh`（`~/.claude/hooks/hook_pre_commands.sh`、正本は
`project-configs/.claude/hooks/hook_pre_commands.sh`）が `ask` を返し、
Claude Codeが実行前承認を求めてきた場合に、このスキルの手順で応答する。

危険検知そのものは上記フックが担うため、このスキル自身は正規表現マッチ処理を
複製しない（検知ロジックの二重管理を避ける）。

## 手順

1. 承認待ちのコマンド・操作が何をするかを特定する
2. 以下を平易な日本語で示す:
   - 何が起きるか(対象のテーブル・ファイル・ブランチ・リソース)
   - 元に戻せるか、戻せる場合はその手段
   - 通常操作との違い(なぜ`ask`判定になったか)
3. 要約を提示したうえで、実行してよいか改めて確認する
4. 承認が得られるまでツールを直接呼び出さない

## 禁止事項

- 要約を出さずに危険操作を直接実行しない
- 読み取り専用操作・通常のファイル編集にはこの手順を適用しない(過剰発動を避ける)
