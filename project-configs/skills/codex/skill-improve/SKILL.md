# Skill Improve

## Purpose

Capture what worked, what failed, and how to make the next run smoother.

## Use This Skill To

- Record lessons from a task
- Note mismatches between intent and implementation
- Update project notes or alignment records
- Tighten workflow guidance when a pattern repeats

## Process

1. Note the main success and the main failure, if any.
2. Record the mismatch in the project notes if the repo uses them.
3. Add a short lesson that helps the next run.
4. Update the skill if the same issue keeps recurring.

## Guardrails

- Keep the reflection short and concrete.
- Do not turn this into a long retrospective.
- Do not leave a repeated failure undocumented.
